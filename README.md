# CSS Placeholder Text Styling Example

This example demonstrates how to customize the appearance of placeholder text in HTML input fields and text areas using CSS. It showcases the use of various vendor-prefixed pseudo-elements (`::-webkit-input-placeholder`, `::-moz-placeholder`, `:-ms-input-placeholder`) along with the standard `::placeholder` to ensure cross-browser compatibility. Different styling properties like color, font-style, font-weight, and font-size are applied to distinct input fields.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
